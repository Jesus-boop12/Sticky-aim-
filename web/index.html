Getting this onto your Cronus
  1. Install Cronus Zen Studio on a PC or Mac and sign in with your Cronus account. (Titan Two owners: Gtuner IV instead — the flow below is the same, the menus are named differently.)
  2. Connect the Zen to the computer using the PROG port — the small port on the side, not the OUTPUT port the console plugs into. This is the step people get wrong. Zen Studio should show the device as connected; take any firmware update it offers.
  3. Open a new GPC script and paste this one in, then Build it. It should compile with no errors — if it does not, the error message names the line.
  4. Program it into a memory slot and note the slot number.
  5. Unplug from the computer and wire it to the console: the console's USB cable into the Zen's OUTPUT port, your controller into the Zen's INPUT port.
  6. Select your slot on the device — the display shows which one is live. When the script starts you get one rumble pulse per weapon slot number.
  7. Go to a practice range before a real match. Hold the trigger on a wall at about 20m and trim the numbers using the guide in the script header.

Menu names and shortcuts move around between Zen Studio versions — if something here does not match what you see, look for the equivalent Build / Program action.

It compiled but nothing happens in game

  • Wrong slot selected on the device, or the master toggle is off — hold the modifier button and press D-pad down to toggle it back on.
  • The script is set to only compensate while ADS and you are hip-firing. Turn that off in the Tune tab if you want it always on.
  • Your in-game deadzone is larger than the pull, so the game throws it away. The Tune tab warns you when that happens.
  • Controller layout mismatch — an Xbox script on a PlayStation pad watches the wrong buttons. Switch the controller setting and re-generate.
