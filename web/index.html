How to load this onto a Cronus device
  1. Open Cronus Zen Studio (or Gtuner for a Titan) and sign in.
  2. File → New GPC Script, paste this in, then Build (F7). It should compile with no errors.
  3. Program the script to a memory slot and switch to that slot on the device.
  4. Go to a practice range, hold the trigger on a wall and trim the numbers as described in the script header.
