# Ready-made scripts

Generated by the app, compile-clean, and safe to paste straight into Zen Studio.
Trim them on a range before you rely on them — the header of each file tells you
which numbers to change and in which direction.

| File | What it is |
|---|---|
| `warzone-universal.gpc` | **One script for every Warzone gun.** Eight profiles, one per weapon class, each built from every gun of that class in the 175-weapon pool. Follows your weapon-swap button: set your primary and secondary once and it flips with you. |
| `warzone-mpc-25-sens6.gpc` | A single-weapon script for the MPC-25, at sens 6 / ADS 0.85. |
| `mw3-sample.gpc` | Three MWIII weapons in one script — MCW, Striker, KATT-AMR — switched with the modifier + D-pad. |

All of these assume an Xbox layout. For a PlayStation pad, regenerate from the
app with the controller setting changed: the button constants differ, and a
script watching the wrong buttons does nothing.
